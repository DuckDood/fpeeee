# FPE(eee)
## Funky Physics Engine(eee) is a portable, verlet-integrated physics engine.

![Cloth showcase](cloth.gif)

# Try it
There are some simple web demos to showcase the features [here](https://duckdood.github.io/physics_demo)

# Quickstart
`git clone https://github.com/duckdood/fpeeee && cd fpeeee && make`
You will find simple demos in the build/ directory.

# Features
* Physics using second-order verlet integration
* Supports 2D and 3D environments
* Distance and spring constraints
* Spatial partitioning for handling thousands of balls at once
* Dynamic walls that can have velocities and can be pushed around, possibly allowing for full rigidbody interactions!
* Written fully in C for portability and interoperability
